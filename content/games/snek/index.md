### How to play

- Use the arrow keys to steer the snake.
- Eat the red apples to grow and score (100 points each).
- Don’t run into yourself — the edges wrap around.
- Press **Z** (A) after a game over to restart.

On mobile the embedded game is hidden; use the button to open it in a new tab.

### About the game
Classic snake for VGC Zero: a green snek, red apples, and a high score that sticks. The playfield wraps at the edges, so only your own tail can stop you. Built with the chili-chip 32blit SDK for the handheld, desktop, and the web.
