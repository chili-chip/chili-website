### How to play

- Use the arrow keys to move the falling piece.
- Press **Up** to rotate clockwise.
- Hold **Down** for a soft drop.
- Press **Escape** (MENU) after a game over to restart.

On mobile the embedded game is hidden; use the button to open it in a new tab.

### About the game
A classic Tetris for VGC Zero — with a chili twist. Guide tetrominoes into the 10-wide well, clear complete lines, and chase a higher score while a chiptune loop plays in the background. The next piece is shown beside the playfield so you can plan ahead. Built with the chili-chip 32blit SDK for the handheld, desktop, and the web.
